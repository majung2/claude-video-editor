# 감사일기 릴스 형식

## 원본
- **메인 영상 1개**: 카메라를 보고 그날의 감사 제목을 말하는 영상 (보통 1~3분, 다시 찍은 테이크 섞임)
- **B-roll (없을 수도 있음)**: 감사 제목마다 관련 사진·영상 (커피, 동료, 퇴근길 노을 …). 다른 사람 얼굴이 나올 수 있다 → 블러 필수.

## 완성본 구성 (30~60초, 1080×1920)
| 구간 | 길이 | 내용 | 화면 |
|---|---|---|---|
| 훅 | 2~3.5초 | 오늘 가장 진한 감사 한 문장 (본문에서 가져온 티저) | 얼굴 + 화면 훅 문구(첫 2.4초) |
| 인트로 | 1~3초 | "오늘의 감사일기" 같은 짧은 시작 (길면 자른다) | 얼굴 |
| 감사 1…N | 항목당 5~15초 | 무엇이 감사했는지 + 왜 | 말 시작 단어에 B-roll 1개, 나머지는 얼굴 |
| 마무리 | 2~4초 | 한 줄 정리 / 다음에 또 | 얼굴, 끝 0.5초 여유 |

## 톤
- 따뜻하고 차분하게. 과장·낚시 금지 — 훅과 썸네일은 실제 내용과 맞아야 한다.
- 브랜드 톤 `warm`: 밈 없음, 전환은 컷·페이드·슬라이드, 플래시·휩 없음.
- 말투는 살린다(구어체). 자막은 맞춤법만 다듬는다.
- 속도는 1.0 (말이 아주 느릴 때만 1.1). 쉼은 tight 기본, 감정이 실린 쉼은 남긴다.

## 썸네일
- 젠세리프 폰트, 2줄 이하, 강조 단어 1개(따뜻한 노랑).
- 베스트 장면: 표정이 살아 있는 프레임 또는 대표 감사의 B-roll(블러된 것만).
- 후보 3장을 서로 다른 콘셉트로.

## 소리
- 잔잔한 BGM(있을 때만), 목소리 아래 −15dB 정도, 핵심 문장에서 더 낮춤.
- 효과음은 적게: 훅 시작, 훅→본론, 감사 항목 등장(pop), 마무리(ding).
