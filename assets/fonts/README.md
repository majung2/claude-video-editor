# 폰트

폰트 라이선스상 파일은 저장소에 올리지 않습니다 (.gitignore). 원본은 아이클라우드 드라이브 `크리에이터` 폴더에 있습니다.

| 위치 | 폰트 | 쓰는 곳 | 등록 |
|---|---|---|---|
| `assets/fonts/` | 젠세리프 (`ZEN-SERIF-TTF-Regular.ttf`) | 썸네일 제목, 영상 첫 2.4초 화면 훅 문구 | 썸네일은 자동, 훅 문구는 `python3 tools/fonts.py heading majunge` |
| `assets/fonts/subtitle/` | 메모먼트 꾹꾹체 (`TalkFile_MemomentKkukkukk.ttf`) | 영상 자막 | `python3 tools/fonts.py subtitle majunge` |
