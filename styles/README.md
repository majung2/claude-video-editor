# 편집 스타일

이 툴킷은 편집 스타일을 여러 개 담도록 되어 있습니다. 전사·컷·자막·B-roll·효과음·렌더 같은 단계와 도구는 모든 스타일이 같이 쓰고,
**스타일마다 다른 것(모습, 형식, 사용자 결정)만** `styles/<스타일>/` 에 둡니다.

| 스타일 | 폴더 | 감독관 스킬 | 상태 |
|---|---|---|---|
| 감사일기 | [`gratitude/`](gratitude/README.md) | `/gratitude-reels` | 사용 중 |

## 스타일 폴더에 들어가는 것

| 파일 | 필수 | 내용 |
|---|---|---|
| `README.md` | ✓ | 스타일 소개, 기본 모습 표, **사용자가 정한 것**. 이 파일이 있어야 `job.py new --style` 이 스타일로 인식 |
| `config.json` | 보통 | 자막·훅·B-roll·효과음 등 스타일 기본값 |
| `thumb.json` | 썸네일을 쓰면 | 썸네일 문구 모습 — `tools/thumbs.py` 가 영상의 스타일에 맞춰 읽음 |
| `render.py` | 엔진 모습을 바꾸면 | `patch-kit` / `check` / `props` (감사일기 `render.py` 참고) |
| `references/` | 선택 | 레퍼런스 분석, 형식 규칙 |

감독관 스킬은 Claude Code 규칙상 `.claude/skills/<스타일>-reels/SKILL.md` 에 둡니다(감사일기: `gratitude-reels`).

## 새 스타일 추가하기

1. **레퍼런스 정하기:** 따라 하고 싶은 릴스 2~3개를 원본 폴더에 모읍니다. Claude에게 "이 레퍼런스 분석해서 새 스타일 만들자"라고 하면 측정부터 시작합니다.
2. **폴더 만들기:** `styles/<영문 이름>/README.md` 를 만들고, 감사일기 README 처럼 기본 모습 표를 채웁니다.
3. **설정:** 필요한 값만 `config.json`·`thumb.json` 에. 감사일기 것을 복사해 고치는 게 빠릅니다.
4. **렌더 모습이 다르면 `render.py`:** 렌더 엔진(`reels/`)은 모든 스타일이 같이 쓰므로 패치는 **덧붙이기만** 하고,
   새 스타일의 props 일 때만 동작하게 합니다(예: 새 자막 모드 이름). 기존 스타일의 화면이 바뀌면 안 됩니다.
   엔진 준비 스크립트(`setup-mac.sh`, `tools/cloud_setup.sh`)는 `styles/*/render.py patch-kit` 을 모두 돌립니다.
5. **감독관 스킬:** `.claude/skills/gratitude-reels/SKILL.md` 를 복사해 `<스타일>-reels` 로 만들고, 스타일 폴더 경로와 형식만 바꿉니다.
   담당자(`.claude/agents/`)는 공용이라 그대로 씁니다. 스타일 전용 단계가 생기면 담당자 지시문에 "<스타일> 전용"으로 표시해 덧붙입니다.
6. **표에 추가:** 이 파일의 표, 루트 `README.md` 와 `CLAUDE.md` 의 스타일 표에 한 줄씩.
7. **첫 영상으로 검증:** `job.py new <id> … --style <스타일>` 로 한 편을 끝까지 편집하며 결정을 `README.md` 의 "사용자가 정한 것"에 쌓습니다.

## 지키는 것
- 스타일 전용 결정은 그 스타일 `README.md` 에만 — 루트 `CLAUDE.md` 에는 모든 스타일에 해당하는 것만.
- 브랜드(`brands/majunge/`)·폰트·효과음 파일(`assets/`)은 사람 단위라 공용. 스타일이 다른 폰트·소리를 쓰면 `config.json` 에서 파일을 고릅니다.
- 공용 도구(`tools/`)에 스타일 이름을 박아 넣지 않습니다. 스타일마다 다른 값은 `styles/<스타일>/` 에서 읽게 합니다.
