# 자유형식 스타일 (`free`)

**영상과 편집 지시를 주면 그 지시대로** 편집하는 스타일입니다. 단, **썸네일 형식·훅·컷·자막 4가지는 공통 스펙**이라
지시와 상관없이 항상 감사일기 방식으로 들어가고, 나머지(B-roll, 효과음, 색, 음악, 장면, 엔드카드, 속도·구간 등)가 지시대로 바뀝니다.
"앞 3초 잘라줘", "1.2배속", "사진은 꽉 차게", "얼굴 밝게", "끝에 팔로우 문구" 처럼 자연스럽게 말하면
Claude가 지시서(`edit/<id>/brief.json`)로 옮기고, 한 번 확인받은 뒤 필요한 단계만 돌립니다.
화면 부품은 감사일기 툴킷과 IT Reelsmaker 에 이미 있는 것을 빌려 씁니다 — 아래 "빌려 쓸 수 있는 부품".

- 감독관 스킬: `/free-reels` (`.claude/skills/free-reels/SKILL.md`)
- 원본: 대화에 직접 올리거나, 아이클라우드 `크리에이터/자유편집/촬영본` (또는 말해 준 경로) → 결과물은 Mac 툴킷 `out/<id>/` (아이클라우드 업로드 없음, 2026-10-24)
- 영상 등록: `python3 tools/job.py new <id> --main <메인 영상> --broll <사진…> --style free` — id 는 `<날짜>-<짧은 이름>` (예: `2026-10-11-카페`)

## 어떻게 진행되나

```
영상 + 지시
  → ① 지시서: 지시를 brief.json 으로 옮김 → render.py brief 로 요약
       "지시대로 할 것 / 지시에 없어 기본값으로 할 것 / 못 하는 것과 대안" 을 보여 주고 한 번 확인
  → ② 필요한 단계만: 전사 · 훅 · 컷 · 자막 · 썸네일 · B-roll(얼굴 블러) · 효과음·음악 · 디자인 장면
  → ③ 렌더 · 검수 · 마스터링 → out/<id>/
  → ④ 피드백도 지시처럼: 지시서를 고치고 영향받는 단계부터 다시
```

## 공통 스펙 — 항상 (`config.json` → `common`, 사용자 결정 2026-10-11)

| 항목 | 감사일기 방식 그대로 | 지시로 바꿀 수 있는 세부 |
|---|---|---|
| 썸네일 형식 | 후보 3장, 영상과 별개 파일. 레퍼런스 "ENTP가 INFP를 좋아하는 이유"(2026-10-11) 모습: 젠세리프 크게(176px, 긴 줄은 폭에 맞춰 축소)·촘촘한 줄 간격(1.05)·**왼쪽 정렬**, **얼굴 바로 아래**(턱 아래 2.5%), 민트·크림·연분홍이 비스듬히 되풀이되는 펄 그라데이션, 도톰한 입체, 옅은 그림자, 오른쪽이 살짝 올라감, **굴곡은 왼쪽 아래에서 시작해 오른쪽 위에서 끝남**. 장면은 얼굴이 화면 위쪽에 있는 것 우선 | 문구, 장면, 영상별 `edit/<id>/thumb.json` |
| 훅 | 말한 문장 중 후보 3개 → 선택 → 그 구간을 맨 앞에, 썸네일 글씨로 한 글자씩 타이핑 + 글자마다 타닥 | 훅 문장을 직접 지정 |
| 컷 | 다시 말한 곳·더듬은 곳·같은 말 반복·긴 쉼 전부 빼기 (늘어진 단어는 재전사로 확인) | 잘라낼/남길 구간, 속도, 목표 길이 |
| 자막 | 메모먼트 꾹꾹체, 흰 글자+얇은 검은 외곽선, 74.5% 높이 한 줄, 단어가 제자리에 나타남, 마침표 없음, 들은 대로 | 크기·위치·색·외곽선 |

지시서가 이 4가지를 다르게 적어도(예: "자막 없이") 공통 값으로 두고 지시서 확인 때 짚어 줍니다.
사용자가 "이번 영상만 자막 없이"처럼 분명히 말하면 그 영상의 `brief.json` 에 `"common_off": ["subtitles"]` 를 적어 끕니다.

## 공통 스펙 밖에서 지시에 없을 때의 기본값 (`config.json` → `defaults`)

| 항목 | 기본값 |
|---|---|
| B-roll | 80% 카드 + 가로 사진은 머리 위 작게, 하드컷, 1.05배 확대. 다른 사람 얼굴 블러(항상) |
| 속도 · 구간 | 1.0배, 전체 |
| 화면 움직임 | 없음 |
| 색 보정 · 효과음(훅 타닥 외) · 음악 · 장면 · 엔드카드 | 없음 |
| 소리 | −14 LUFS, 피크 −1dB 이하. BGM 을 넣으면 목소리보다 20~25dB 아래(기본 22) — 공통 `config/audio.json` |

## 빌려 쓸 수 있는 부품

**감사일기에서 더** (`config.json` → `presets`, 지시서에 이름만 적으면 됨)

| 부품 | 내용 |
|---|---|
| B-roll 카드 | 세로 사진 80% 카드, 가로 사진 머리 위, 하드컷, 부드러운 1.05배 확대 (기본값과 같음) |
| 얼굴 밝기 보정 | 어두운 곳 위주로 살짝 밝게 (10.7·10.8 에 쓴 곡선) |
| 감사합니다 뽁 | 특정 말을 할 때마다 뽁 — 다른 말·다른 소리로 바꿔 쓸 수 있음 (`sfx.on_words`) |

**IT Reelsmaker 에서** (감독관이 reel.json·visual_plan 으로 넣음)
자막 typewriter/accent/plate · 위쪽 훅 문구 · 디자인 장면(인용·숫자·목록·CTA·표지) · 가상 카메라(확대·휙 넘기기) ·
엔드카드 · framed 형식(창 안에 영상) · 자막 번역·.srt · 사람 오려내기 · 밈·코드 장면 인서트

**공용 도구에서** 얼굴 블러(`/faceblur`) · 썸네일 문구(`tools/thumbs.py`, 영상마다 `edit/<id>/thumb.json` 으로 바꿀 수 있음) ·
효과음 합성(`tools/sfx.py`: whoosh·pop·ding·rise·키보드·마우스) · 자막 끊김 미리보기 · 클라우드 세션 준비·전사

## 못 하는 것 (지시받으면 대안을 말함)
- 음악·효과음 파일을 인터넷에서 찾아오기 → `assets/music/`·`assets/sfx/` 에 넣어 주거나 합성음으로
- 영상에 없는 장면 만들기(AI 영상 생성) → 디자인 장면(글자·숫자·목록)이나 가진 사진으로
- 렌더 엔진에 없는 효과(3D 전환, 파티클 등) → 비슷한 기존 효과를 제안. 자주 쓰게 되면 `render.py` 에 부품으로 추가

## 사용자가 정한 것 (다음 영상도 그대로)
- 공통 스펙 = 썸네일 형식·훅·컷·자막, 감사일기 방식으로 항상 (2026-10-11)
- 썸네일 형식은 레퍼런스 "ENTP가 INFP를 좋아하는 이유"에 맞춤: 왼쪽 정렬, 얼굴 바로 아래, 펄 그라데이션, 굴곡은 왼쪽 아래에서 시작해 오른쪽 위에서 끝남 (2026-10-11)
- (피드백 중 "앞으로도" 라고 하면 여기와 `config.json` defaults 에 더 적습니다)

## 이 폴더

| 파일 | 내용 |
|---|---|
| `README.md` | 이 문서 |
| `config.json` | 공통 스펙(`common`, `locked`) · 지시에 없을 때의 기본값(`defaults`) · 감사일기에서 더 빌려 올 부품(`presets`) |

| `render.py` | `brief`(지시서 요약·확인) · `props`(렌더 설정을 지시서 모습으로) · `keys`(지시서 효과음) · `patch-kit`/`check`(감사일기 엔진 부품 확인 — 자체 패치 없음) |

## 렌더 순서 (감독관)
```bash
python3 styles/free/render.py brief edit/<id>                                             # 지시서 확인
python3 tools/plug.py rm visual_plan export edit/<id> --remotion reels --props edit/<id>/reelkit-props.json
python3 styles/free/render.py props edit/<id>/reelkit-props.json --edit edit/<id>         # 지시서 모습으로
python3 styles/free/render.py keys --edit edit/<id>                                       # 지시서 효과음
cd reels && npx remotion render ReelKit out/<id>.mp4 --props=<절대경로>/edit/<id>/reelkit-props.json
python3 tools/plug.py rm master_audio reels/out/<id>.mp4 -o edit/<id>/master.mp4 --sfx edit/<id>/sfx.json
```
