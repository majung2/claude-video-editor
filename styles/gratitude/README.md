# 감사일기 스타일 (`gratitude`)

카메라를 보고 그날의 감사한 일을 말하는 셀카 영상을 인스타 릴스로 만드는 스타일입니다.
레퍼런스 릴스 2개를 측정해서 맞춘 모습에, 10.6 감사일기를 편집하며 정한 것들을 더했습니다.

- 감독관 스킬: `/gratitude-reels` (`.claude/skills/gratitude-reels/SKILL.md`)
- 원본 폴더(아이클라우드): `크리에이터/감사일기/촬영본` → 결과물은 Mac 툴킷 `out/<id>/` (아이클라우드 업로드 없음, 2026-10-24) → 최종 컨펌 뒤 쓴 원본은 촬영본에서 삭제 (`tools/cleanup_src.py`, 2026-10-22)
- 영상 등록: `python3 tools/job.py new <id> --main <메인 영상> --broll <사진…> --style gratitude`

## 사용자가 정한 것 (다음 영상도 그대로)
- 썸네일 문구: 공통 썸네일 스펙(`config/thumb.json`)을 따른다 — 왼쪽 정렬, 얼굴 바로 아래, 펄 그라데이션, 왼쪽 아래→오른쪽 위 굴곡. 강조색 없음. (2026-10-11 레퍼런스 반영, 10.7·10.8 썸네일 다시 만들어 확정. 예전 결정 '가운데 정렬'은 바뀜)
- 훅: 위쪽 훅 문구 없이, 훅 문장을 썸네일 스타일로 한 글자씩 타이핑(기울기 없음) + 글자마다 타닥 소리.
- **훅 색 #FCEED1 + 연한 그림자, 말자막은 흰색 + 진한 그림자** (사용자 결정 2026-10-24): 말자막은 **흰 글자 + 진한 그림자, 검은 외곽선 없음**(`subtitles.softShadow` alpha 0.75, outline 0 — 같은 날 다시 정함), 훅 글씨만 그라데이션 대신 #FCEED1 한 색 + 연한 그림자(`hook.color`, `hook.shadow`). 예전 '흰 글자 + 검은 외곽선', '파스텔 그라데이션 훅'은 바뀜.
- 자막: 마침표 없음, **한 줄씩 통째로**(`subtitles.reveal: line`)·**56px** (2026-10-23, 19일차 — 예전 '제자리 타자기·78px'은 바뀜). 오인식은 `fix`/`fix_at`. 사용자가 고쳐 달라고 한 자막 글자도 `fix` 로 (19일차 '가져간'→'가져온').
- **말자막 한 줄 약 10자** (사용자 결정 2026-10-24, 20일차): `config.json subtitles.maxWidth` 480 (예전 842 ≈ 15자). 넘으면 어절 단위로 나누고, 단어가 끊길 상황이면 조금 길어져도 됨.
- B-roll 사진은 부드럽게 1.05배 확대.
- 얼굴 밝기 보정: 어두운 곳 위주로 살짝 밝게 — cut.json `look.correct` = `curves=all='0/0 0.25/0.31 0.5/0.58 0.75/0.81 1/1',eq=saturation=1.04` (10.7·10.8, 2026-10-10)
- 썸네일에 회차 표기: 후보마다 sub `"감사일기 #<회차>"` (제목 아래 작은 노랑 글씨, 제목 시작점보다 살짝 뒤— `thumb.json` thumb_sub_dx 11, 2026-10-15 10.11 에서 1px씩 비교해 결정). 회차 = 영상에서 말한 "N번째" (10월 시리즈는 날짜와 같음).
- 썸네일 글자 뒤: 아래쪽으로 길고 완만하게 어두워지는 연한 그라데이션(`thumb_shade_style: fade`, 최대 약 40%). 썸네일은 원본 전체(편집에서 잘린 장면 포함)에서 표정 좋은 장면을 골라 후보를 낸다
- 효과음: "감사합니다" 말 시작마다 뽁, 훅 타이핑 타닥. 마지막 "감사합니다"에 ding 없음, 감사 2·3 등장 pop 없음.

- **인트로는 항상 조금 확대** (2026-10-18, 10.14): 인트로 구간만 얼굴 중심으로 약 1.35배 확대해 쓴다. 방법: 원본 앞부분을 `crop` 으로 확대한 별도 파일(`footage/<id>/intro_zoom.mp4`)을 만들어 cut.json `sources.intro` 로 넣고 인트로 range 의 `source` 를 `intro` 로. 인트로 뒤 말 없는 부분은 자른다. 인트로 속도는 영상마다 정함(10.14 는 1.2배속 — `sources.intro.speed`). 10.15: 확대는 맨 앞 훅의 마지막 핵심 말("전화위복")에만 넣고, 그 뒤 인트로 문장은 원본 크기로 (사용자 수정 요청 2026-10-19) — 어디를 확대할지는 영상마다 확인.
- **확대는 훅에서만, 얼굴은 화면 가운데** (2026-10-23, 19일차 — 위 인트로 확대 규칙을 바꿈): 확대 파일(`intro_zoom.mp4`, 1.35배)은 훅 range 에만 쓰고, 인트로 첫 문장('와우 월요일 아침입니다' 등)부터는 원래 크기. crop 위치는 YuNet 으로 찾은 얼굴 중심이 화면 가운데에 오도록 (`crop=800:1422:<얼굴x−400>:<얼굴y−711>`). 확대 화면에서도 훅 글씨가 머리 위 빈 공간에 들어가게 확인.

- 물방울 효과음 (2026-10-15, 10.11): `assets/sfx/waterdrop_heavy.wav`(묵직·울림 약 3초, 사용자 선택) · `assets/sfx/waterdrop.wav`(조금 맑게, 울림 약 2초). 10.11 훅에서 물방울 확대 순간 1번, 이때 훅 타닥 소리는 뺐다 — 다음 영상 기본값은 아님(그때 정함)

- **훅 글씨 자리는 얼굴 위치로 자동** (사용자 결정 2026-10-24, 19일차 '머리 위'를 바꿈): 촬영 원본의 얼굴이 화면 가운데보다 **아래면 상단(머리 위), 위면 하단**(1430). `render.py props` 가 훅 구간 화면에서 얼굴을 찾아 정한다(`config.json hook.autoPos`). 나머지 자막은 항상 원래 위치(1430).
- **마지막 멘트 뒤 약 1초 여유** (사용자 결정 2026-10-24, 19일차의 2초에서 줄임): 마지막 말 뒤 영상 장면을 1초 정도 남기고 자른다 — 띡 끝나지 않게. 마지막 range 끝을 말 끝 + 1초로 (바로 뒤에 다른 말이 있으면 말소리 없는 장면 1초를 beat `마무리` range 로).
- **썸네일 제목 자리도 얼굴 위치로 자동** (사용자 결정 2026-10-24, 18·19일차 '머리 위'를 바꿈): `thumb.json` thumb_pos `auto` — 얼굴이 화면 가운데보다 **아래면 머리 위**(thumb_top_mid_y 0.27, 크기 176 그대로·이마 조금 덮어도 됨), **위면 얼굴 바로 아래**(공통 below_face). '감사일기 #N' 은 제목 아래 내림 글자(g 등)와 살짝만 떨어지게 `thumb_sub_dy` 18px.
- **훅 글씨는 항상 머리 위, 안전영역 안** (사용자 결정 2026-10-25, 21일차 — 위 '얼굴 위치로 자동'을 바꿈): `config.json hook.alwaysAbove` true. 얼굴 위치와 상관없이 머리 위에 두고, 글자 윗부분이 안전영역(`config/safe_zone.json`) 위쪽 경계 아래로 오게 한다.
- **문장이 끝나면 다음 자막으로** (사용자 결정 2026-10-25, 21일차): `subtitles.sentenceBreak` true — '~니다/~요/~죠' 나 . ! ? 로 끝난 단어 뒤에서 덩어리를 끊는다. 예: '봐주셔서 감사합니다' / '내일도 봐요'.
- **B-roll 카드도 안전영역 안** (2026-10-25): `render.py props` 가 카드·작은 사진 상자를 안전영역으로 줄인다(카드 [108, 240, 782, 1290]).
- **앱 화면 캡처 B-roll** (21일차): 말하는 기능이 보이게 해당 부분만 밝게 두고 나머지는 어둡게, 브랜드 노랑(#FFD678) 테두리로 하이라이트.
- **썸네일 제목은 사용자가 정해 주면 그 문구로** (예: 19일차 '노트북 두고 출근했어요').
- **영어로 찍은 영상 = 두 언어 자막** (2026-10-22, 18일차): 위 영어(젠세리프, 버터크림 `#FFF1C1`, 62px), 아래 한글 번역(메모먼트 꾹꾹체 흰색 56px), 둘 다 한 줄씩 통째로. 영어 한 줄 25자 안팎, 영어 줄마다 한글 한 줄(어순이 엇갈리면 한글을 그 줄 뜻에 맞게). 훅에는 한글 없음.
  방법: `edit/<id>/dual_src.json` 의 pairs(영어 줄, 한글) — 영어 단어 순서가 captions 와 같아야 함 → `dual.json`(줄마다 시작·끝) → `render.py props … --dual edit/<id>/dual.json`. 기본값 `config.json` → `dual`.
  훅 타닥 소리는 영어 글자가 많아 3개 중 1개만 남긴다(18일차). 다시 말한 곳이 많아 단어 시간이 뭉친 구간은 반드시 다시 받아써서 자막 타이밍을 맞춘다(18일차 셔틀버스 부분).
- **사용자 요청이면 단어 단위로도 다듬는다** (18일차): 'still' 하나만 빼기, 'since' 를 빼고 앞에서 말한 'and' 를 붙이기 등. 자른 뒤 그 소리를 다시 받아써 남은 소리가 없는지 확인.

## 렌더 순서 (감독관 7단계)
```bash
python3 tools/plug.py rm visual_plan export edit/<id> --remotion reels --props edit/<id>/reelkit-props.json
python3 styles/gratitude/render.py props edit/<id>/reelkit-props.json --edit edit/<id>   # 감사일기 모습으로
python3 styles/gratitude/render.py keys --edit edit/<id>                                  # 훅 타닥·감사합니다 뽁
cd reels && npx remotion render ReelKit out/<id>.mp4 --props=<절대경로>/edit/<id>/reelkit-props.json
python3 tools/plug.py rm master_audio reels/out/<id>.mp4 -o edit/<id>/master.mp4 --sfx edit/<id>/sfx.json
```

## 자주 생기는 문제 (감사일기)
| 증상 | 원인과 해결 |
|---|---|
| 화면에 "ReelKit template" 글자 | 훅 문구가 비어 엔진 기본값이 나온 것. `render.py props` 를 거치면 꺼집니다 |
| B-roll 사진이 흔들림 | 예전 방식(미리 만든 확대 영상). 지금은 엔진이 직접 부드럽게 확대합니다 → `render.py patch-kit` |
| "감사합니다" 효과음이 안 들림 | 말 첫 음절과 겹쳐 묻힌 것. `config.json` 의 `click_below_db`(숫자가 작을수록 큼) |
| `kit.py update` 뒤 자막·카드 모습이 원래대로 | 엔진을 업데이트하면 패치가 지워집니다 → `python3 styles/gratitude/render.py patch-kit` |
