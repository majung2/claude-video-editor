# 감사일기 레퍼런스 분석 (2026-10-08)

iCloud `크리에이터/감사일기/레퍼런스/` 의 레퍼런스 릴스 2개(42~44초, 1080×1920)를 프레임·오디오로 측정한 결과.
검증: 이 값으로 레퍼런스 영상 위에 자막을 다시 입혀 보니 원래 자막과 위치·크기가 거의 정확히 겹쳤다.
감사일기 편집의 **목표 모습**은 이 문서다. `format.md` 는 이걸 툴킷 규칙으로 옮긴 것.

## 1. 구성
| 순서 | 말 | 화면 |
|---|---|---|
| 1 | "감사 일기 N일차" | 얼굴 |
| 2 | "감사한 것들을 읽어 보겠습니다" | 얼굴 |
| 3~5 | 감사 3개 — "첫 번째 / 두 번째 / 세 번째" 로 시작, 각 항목은 "~것 감사합니다" 로 끝 | 말하는 동안 B-roll 카드 1~2문장 |
| 6 | 마무리 인사 (예: "오늘도 와 주셔서 감사합니다") | 얼굴 |

- 셀카 구도의 토킹헤드, 한 테이크, 자연스러운 목소리.
- 제목 카드·스티커·이모지·줌 효과 없음. 화면 전환 효과 없음(전부 하드컷).
- 말 사이 긴 쉼은 잘라 템포가 빠르다 (쉼 0.36초 이상 → 앞뒤 0.18초만 남김).
- 잔잔한 BGM 은 있어도 되고 없어도 된다 (목소리 아래 깔리는 정도).

## 2. 자막 (측정값)
| 항목 | 값 |
|---|---|
| 글자 | 흰색, 굵게, 얇은 검은 외곽선(약 3px) + 옅은 그림자 |
| 폰트 | 메모먼트 꾹꾹체 (`assets/fonts/subtitle/TalkFile_MemomentKkukkukk.ttf`) — 1920 높이 기준 약 78px 에서 레퍼런스와 크기가 맞음 |
| 위치 | 가로 가운데, 세로 중심 y ≈ 74.5% (1920 기준 약 1430px) |
| 줄 | 한 줄. 최대 폭 ≈ 화면의 78% (좌우 여백 약 110px) |
| 등장 | **타자기식**: 문장 전체가 가운데 정렬로 자리를 먼저 잡고, 단어가 말하는 속도에 맞춰 왼쪽부터 제자리에 하나씩 나타남 (재정렬 없음) |
| 템포 | 단어·덩어리 하나가 약 0.3~0.9초마다 추가 |
| 문장 사이 | 문장이 끝나면 약 0.3초 비었다가 다음 문장 |
| 단위 | 자막 1개 = 말한 문장 1개 |

## 3. B-roll
| 항목 | 값 |
|---|---|
| 형태 | 사진·영상이 화면의 약 80% × 80% 크기 카드로, 가운데에 얼굴 위로 뜸 |
| 맞춤 | 잘리지 않게 전체가 보이도록(contain) |
| 길이 | 해당 감사 항목을 말하는 1~2문장 동안. 목소리는 계속 |
| 전환 | 없음 — 하드컷으로 나타나고 사라짐 |
| 가로 사진 | 작은 사진(PiP)으로 화면 위쪽(y ≈ 40%), 폭 약 55% |
| 자막 | B-roll 이 떠 있어도 자막은 계속 보임 |

## 4. 툴킷에서 레퍼런스대로 만드는 방법
키트(`reels/src`)에 감사일기 모드를 더해서 레퍼런스와 같게 렌더한다. 플러그인 스크립트는 그대로 두고,
플러그인이 만든 렌더 설정(props)을 `styles/gratitude/render.py` 가 바꾼다 — 플러그인을 업데이트해도 유지된다.

| 레퍼런스 | 툴킷 |
|---|---|
| 가운데 정렬, 한 줄, 흰 글자 + 얇은 검은 외곽선, y ≈ 74.5% | 자막 모드 `gratitude` (`kit/GratitudeSubtitles.tsx`) — 길면 한 줄씩 나눠 차례로 |
| 문장이 자리를 먼저 잡고 단어가 제자리에 나타남 | 같은 방식 (줄 전체를 먼저 배치, 말한 단어만 보이게) |
| 80% 카드 B-roll, 사진 전체가 보이게, 하드컷 | B-roll 모드 `card` (`kit/Inserts.tsx`) |
| 가로 사진은 작게 위쪽 | 폭이 높이의 1.15배 넘는 사진 → 폭 55%, 세로 중심 40% |
| 줌·카메라 무빙 없음 | `drift: false`, 가상 카메라 제거 |
| 긴 쉼 자르기 | 컷편집 페이싱 tight |

순서: 플러그인 `visual_plan export --props` → `python3 styles/gratitude/render.py props edit/<id>/reelkit-props.json --edit edit/<id>` → 렌더.
계획 단계(visual_plan add)에서는 B-roll 을 `replace` 로 둔다 — 플러그인 검증은 얼굴을 덮는 카드를 거부하므로, 카드는 렌더 직전에만 바꾼다.
값 조정: `styles/gratitude/config.json`. 키트를 `kit.py new`/`update` 한 뒤에는 `python3 styles/gratitude/render.py patch-kit` 를 다시 실행한다.

### 일부러 레퍼런스와 다르게 두는 것 (사용자 결정, 2026-10-09)
레퍼런스에 맞춰 "고치지" 않는다.
| 레퍼런스 | 툴킷 (유지) |
|---|---|
| "감사 일기 N일차"로 바로 시작, 제목 카드 없음 | 후커가 고른 티저 훅을 맨 앞에 + 첫 2.4초 화면 훅 문구(젠세리프) |
| 효과음 없음 | 오디오 담당 규칙대로 효과음 (훅 whoosh·감사 항목 pop·마무리 ding 등) |
| 쉼 0.36초 이상 → 앞뒤 0.18초만 남김 | 컷편집 담당 기본 페이싱 tight (쉼 50ms) |

## 5. 측정 방법 (다시 분석할 때)
- 컷: ffmpeg `select='gt(scene,0.25)'` 로 장면 전환 시점.
- 자막: 6fps·540×960 으로 샘플링해 "흰 픽셀 + 근처 검은 외곽" 마스크 → 세로 밀도가 가장 높은 띠 = 자막 위치,
  글자 높이 중앙값 × 1920 / 0.86 = 권장 폰트 크기, 덩어리마다 왼쪽 끝이 고정된 채 오른쪽이 늘면 타자기식.
- 오디오: `silencedetect=n=-40dB:d=0.4` 무음 구간 수로 BGM 깔림 여부.
- 검증: 레퍼런스 자막 문장으로 대본을 만들어 레퍼런스 영상 위에 다시 렌더 → 원래 자막과 겹치는지 비교.
